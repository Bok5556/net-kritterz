# Net Kritterz

This is the official coming soon page for Net Kritterz, an upcoming indie 2D virtual pet remake. The project is currently in early development, and this repository contains the public landing page, early web prototype, and supporting project files.

## About the Project
Net Kritterz is an independent 2D virtual pet revival project inspired by the charm of caring for a digital companion. The goal is to recreate that feel in a fresh and modern browser-friendly experience.

This repository currently serves as the project’s public announcement and landing page while development continues.

## Late 2026 Beta
The Late 2026 Beta is an upcoming preview milestone for Net Kritterz. It is not yet released and is intended as an early testing and feedback phase for the next stage of development.

### Planned Beta Goals
- Test the early player experience
- Gather feedback on visuals, usability, and interaction design
- Validate browser compatibility and performance
- Refine the virtual pet system and core game experience
- Improve project onboarding and documentation before wider release

### Beta Status
- Planned for late 2026
- Not yet publicly released
- Subject to change during active development
- Community feedback will be welcomed once the beta opens
